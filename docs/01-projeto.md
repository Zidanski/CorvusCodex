# 01 — O projeto

## Corvus Codex

Biblioteca colaborativa de estudos. Estudantes **enviam, pesquisam e comentam** materiais de estudo
(livros, resumos, anotações, listas de exercício) uns dos outros. A ideia é ser uma "Wikipédia/Brainly mais leve":
simples, rápida e acolhedora.

- **Corvus** = corvo em latim. O corvo simboliza inteligência e memória.
- **Codex** = o livro antigo, o manuscrito.
- O logo é um corvo pousado sobre um livro aberto (conhecimento compartilhado).

## Pilares

1. **Simplicidade**: código de estudante, fácil de ler e de explicar na apresentação.
2. **Acessibilidade**: contraste AA, navegação por teclado, foco visível, `label` em todo campo, HTML semântico.
3. **Comunidade**: qualquer estudante pode contribuir com material e comentar.

## Funcionalidades previstas

| Funcionalidade | Página |
| --- | --- |
| Página inicial com apresentação | `index.html` |
| Ver todos os materiais (acervo) | `acervo.html` |
| Entrar e criar conta | `login.html` |
| Pesquisar materiais por palavra | `pesquisa.html` |
| Enviar um material novo | `enviar.html` |
| Comentar e ver comentários | `comentarios.html` |

Em aberto (decidir com o grupo): página de detalhe de um material (`material.html?id=...`),
