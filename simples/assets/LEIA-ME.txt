CORVUS CODEX — ASSETS (tema claro)
==================================

Estrutura sugerida no projeto:
  CorvusCodex/
    assets/   ← esta pasta
    fontes/   ← do corvus-codex-fontes.zip
    icones/   ← do corvus-codex-icones.zip
    landing.html, pesquisa.html, ...

O QUE TEM AQUI
  css/tokens.css ........ TODAS as cores, fontes, tamanhos, espaços, sombras (variáveis)
  css/base.css .......... estilos base + componentes (botões, campos, cartões, tags, alertas...)
  logo/corvo.svg ........ símbolo colorido (uso principal)
  logo/corvo-mono.svg ... símbolo de uma cor só (herda a cor do texto)
  logo/corvo-branco.svg . símbolo branco, para fundo azul-escuro
  logo/logo-horizontal*.svg  símbolo + nome + assinatura (cabeçalhos, documentos)
  logo/logo-vertical.svg  versão empilhada (capas, slides)
  logo/simbolo-app.svg .. quadrado azul com corvo branco (ícone de app)
  png/ .................. as mesmas versões em PNG (para slides, Word, Canva)
  favicon/ .............. ícones da aba do navegador e do celular + manifest
  social/og-image.png ... imagem de prévia quando o link é compartilhado (1200×630)
  modelo-pagina.html .... página modelo com o <head> certo, cabeçalho, main e rodapé

REGRAS RÁPIDAS
  1. Inclua os CSS nesta ordem: fonts.css → tokens.css → base.css → icones.css → CSS da página.
  2. Nunca escreva cor solta (#1F5A93) no CSS das páginas: use var(--cor-primaria).
  3. Logo: deixe em volta um espaço livre de pelo menos meia altura do corvo.
     Tamanho mínimo: 24px (símbolo) e 140px de largura (horizontal).
  4. Não estique, não gire, não troque as cores e não ponha sombra forte no logo.
  5. O guia completo está em corvus-codex-guia-de-estilo.html.

Tipografia: Source Serif 4 (títulos) + DM Sans (texto), as alternativas livres
mais próximas das fontes da Anthropic. Ícones: base Lucide (ISC).
