Sobre o projeto

O Corvus Codex é uma biblioteca colaborativa de estudos: estudantes enviam, pesquisam e comentam livros, resumos e anotações uns dos outros.

"Corvus" é corvo em latim, símbolo de inteligência e memória. "Codex" é o livro antigo, o manuscrito.

Projeto do curso de Ciência da Computação do Centro Universitário Dom Helder (Belo Horizonte, MG), 2º semestre de 2026.

Como foi feito

HTML, CSS e JavaScript puros, com Firebase (login com Google, banco de dados Firestore e hospedagem).

Livros de exemplo: textos em domínio público do Wikisource e livros com licença livre. Capas: Open Library.
